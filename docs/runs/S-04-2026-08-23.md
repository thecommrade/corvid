## Gotchas recorded (cost ~40 min tonight)

- **llama-cli at b10581 ignores `-no-cnv` without a tty** for chat-templated models: it loops
  printing `> ` forever (wrote a 200 MB log). Use `-st --single-turn` with `-p` for the
  thesis completion, and prefer llama-bench for numbers.
- **Never `pkill -f` from a compound command that also names the target binary** — it matches
  the command's own shell and kills the whole ssh session. Use `pkill -x <name>`.
- `GGML_RPC_DEBUG=1` produced no output on the prebuilt b10581 binaries (likely needs a debug
  build); the RTT-arithmetic calibration via local-vs-split tg is the substitute (worked).
- Ubuntu's iperf3 package auto-enabled its **system daemon on `*:5201`** on optiplex —
  founder disables with `systemctl disable --now iperf3` (bind-hygiene; CLI stays).
